## Pipeline ช้าที่สุดตรงไหน

ขั้นตอน E2E Tests ช้าที่สุด (ใช้เวลา 1 นาที) เพราะต้องติดตั้งเบราว์เซอร์และรันฐานข้อมูลชั่วคราว
วิธีลดเวลาในอนาคต: อาจจะใช้ Cache ในการเก็บเบราว์เซอร์ให้มีประสิทธิภาพขึ้น หรือทำ Sharding รันเทสต์ขนานกัน

## จำนวน push ที่ใช้ไปในการ debug pipeline วันนี้

ใช้ไปประมาณ 7-8 ครั้ง
ครั้งหน้าจะลดได้อย่างไร: ทดสอบรันคำสั่งต่างๆ (เช่น npm run db:migrate หรือ npx playwright test) และเช็คเรื่อง lockfile ภายในเครื่อง Local ให้ผ่าน 100% ก่อนค่อยกด Push ขึ้น GitHub
