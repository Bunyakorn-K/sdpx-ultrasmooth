## Verification gates

1. Validate JSON/YAML/Markdown artifacts and GitHub metadata.
2. Run `bun run test` and the Playwright smoke test.
3. Run `bun run build` and `bunx tsc --noEmit`.
4. Run a local dev server and verify the homepage in a real browser.
5. Verify staging status and report whether it reflects the current unpushed tree.
6. Run `git diff --check` and inspect the final changed-file list.

- No secrets, credentials, session artifacts, or user data in files or output.
- No commit, push, deploy, or PR creation unless explicitly requested.
